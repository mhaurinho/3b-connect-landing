# Landing 3B Connect

Prévia pública e não indexada da 3B Connect.

A copy descreve o core atual: setup guiado Windows + Hermes, feito com o
participante em uma sessão privada de validação. Os materiais escritos aparecem
somente como apoio; não há oferta de curso, preço ou suporte fechado.

- não possui checkout;
- não coleta dados;
- não carrega JavaScript ou serviços externos;
- publica somente os arquivos sanitizados de `public/`;
- não contém PDFs, documentos editoriais nem validações internas do projeto;
- usa somente imagens e fontes locais incluídas no pacote sanitizado.

O deployment usa `public/` como diretório estático. `SHA256SUMS` registra
exatamente os arquivos aprovados para a prévia.
